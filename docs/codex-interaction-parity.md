# Codex Desktop 交互对齐清单

状态：目标契约（2026-09-14）。本清单描述 PUA 要复刻的 Codex Desktop 工作台交互；Pi 不提供的模型、凭据、工具和扩展能力不在范围内。

## 目标

PUA 的一级对象是任务（Task），项目（Project）用于分组，Pi 会话（Session）是任务的运行资源。用户可以从任意项目创建、恢复、切换、归档任务；任务切换不丢失草稿、附件、滚动位置、运行状态或检查器状态。

## 能力矩阵

| 区域 | 目标行为 | 当前缺口 |
|---|---|---|
| 全局导航 | 新任务、搜索、最近、归档、项目分组、折叠与恢复 | 仅 ProjectNav |
| 项目树 | 项目展开后显示全部任务，当前项目与当前任务独立高亮 | 当前仅当前项目 SessionTabs |
| 任务生命周期 | 创建、恢复、关闭、归档、取消归档、置顶、重命名 | 仅内存创建/关闭/重命名 |
| 任务栏 | 标题、项目、分支、运行状态、分享、更多操作 | 无任务级操作栏 |
| 对话 | 消息操作、工具过程、重试/继续/停止/排队、附件与命令 | Pi 能力分散在 ChatPane |
| 检查器 | 变更、文件、分支、终端与任务上下文联动 | GitPanel 独立 |
| 搜索 | 全局任务、项目内任务、当前对话/终端 | 仅命令菜单与终端搜索 |
| 后台状态 | 离开任务后保留运行、完成、失败、通知 | 仅当前 Session activity |
| 恢复 | 重启后恢复最近任务、布局、草稿与面板状态 | 无持久任务模型 |
| 键盘 | 新任务、切换任务、搜索、聚焦输入、归档、关闭、面板切换 | 仅少量快捷键 |
| 窄窗 | 面板可发现、渐进收缩、状态不丢失 | 入口曾被隐藏 |

## 不可复刻边界

Pi 不支持的云端分享链接、远程任务同步、模型账户与 Codex 服务能力不伪造入口。PUA 只实现本地任务管理、Electron 窗口交互、Pi RPC/PTY、Git 与文件系统可支持的体验。

## 验收原则

每项能力必须有鼠标和键盘路径；异步操作必须显示 pending、成功、失败和恢复；任务切换必须验证身份与草稿 revision；应用重启必须验证持久化恢复；窄窗必须验证功能仍可发现。
