# 排版与注意力层级

## 截图观察（不是品牌 token 测量）

Codex 阅读参考中，回答沿稳定左缘展开，普通段落与列表占主体；少量章节靠字重和段间距分组。用户短消息靠右、浅底，助手正文不重复套卡片或头像标题。侧栏、过程与环境信息退到辅助位置，输入区位于阅读区域底部。截图不能证明其字体、CSS 像素或动效参数。

## 当前问题与实施规则

原紧凑版将控件压到 28px，却同时保留按钮 500、模块标题 600、展示标题 650 和默认 strong 700；正文/辅助仅两档颜色，项目、会话、普通标签和用户作者同时紫色。组合页以演示控件和重复标题为主，没有长回答验证阅读。

本库将操作密度与阅读节奏分开。新增或修改组件、状态色、文字 slot 时先按下表选角色，再检验实际背景对比度与同屏注意力；不能只改字号表。默认系统字体，明确 CJK 回退，不安装或假定加载 Inter。实际命中的字体由浏览器/系统决定，浏览器证据需同时记录 computed stack 与中文、英文、数字的 platform fonts。

| 角色 / token | 用途 | 规格与预算 |
| --- | --- | --- |
| `--ui-font-control` | 导航、按钮、表单 | 13px / 20px / 400；28px 操作高度 |
| `--ui-font-reading` | Chat 与输入正文 | 15px / 1.65 / 400；阅读列上限 720px，窄列自适应 |
| `--ui-font-meta` | 耗时、说明、辅助数据 | 12px / 18px / 400；不以 disabled 淡化有效信息 |
| `--ui-font-heading` | 少量章节、Dialog 标题 | 16px / 24px / 600；回答标题相对正文，正常字距 |
| `--ui-weight-medium` | 当前项、关键操作 | 500；ghost 与普通导航保持 400 |
| `--ui-text` | 主阅读 | 中性正文，不将所有辅助文字提升到主色 |
| `--ui-secondary` | 导航、辅助说明 | 次级有效文本 |
| `--ui-tertiary` | 时间与元信息 | 三级有效文本；与前两档在实背景上均 ≥4.5:1 |
| `--ui-disabled` | 不可用操作 | 独立例外，不能用于元信息 |
| `--ui-link` / `--ui-accent` | 正文链接 / 焦点与关键动作 | 链接有下划线；焦点与重要图标 ≥3:1；选中导航采用中性底与字重 |

## 对话与预览约定

ChatMessage 保持 typed role/author/metadata/children/streaming/error/actions；作者和角色默认视觉隐藏但可访问，元信息单独显示。用户正文右侧有限宽中性 bubble；助手裸正文，系统消息次级色；操作始终可见可聚焦，失败不丢已生成正文。字符串保留换行，React slot 使用正常块排版；prose 样式严格限定 Chat 正文，涵盖段落、标题、列表、链接、代码、引用和表格，不注入 HTML。

组合页保留会话改名、面包屑、折叠过程与检查器。长文滚动区和底部输入区分配独立布局空间，不覆盖末段，不自动追底。测试控制使用可键盘展开的 disclosure，状态目录仍可验证所有状态；四个预览入口保持。只使用本地 fixture，不接入正式 App。

## 验收

同视口明暗 1440/1280/500 截图先看 idle，再看长文的列表、代码与末段；同时检查正文、导航、元信息的字体/字重/行高、真实背景对比度和阅读列宽。Composer 与正文不重叠，最后内容可滚到，窄窗与 Dialog 不横溢出。保留通知、Tooltip 全文、改名、拖拽、GSAP 中断与 reduced/off 回归。测试通过不代表用户视觉批准或真实 Pi 集成。
